Training Data: Class Distribution

The training set is roughly balanced across all ten digits, meaning no digit class is over- or under-represented. This is good for training because the model does not need special handling like class weighting to avoid biasing toward any particular digit.

Model Performance: Per-Class F1 Score

F1 scores vary slightly by digit. Digits with more visual variation in how people write them (like 9, 7, and 2) tend to score lower because they share strokes with other digits and are easier to confuse. Digits with simple, consistent shapes (like 0 and 1) score highest.

Confusion Matrix

Most predictions land on the diagonal, meaning the model is getting them right. The largest off-diagonal cells reveal which digit pairs the model confuses most often. These are typically digits that share similar strokes or curves, like 2 and 7, or 4 and 9. Exact numbers update after each retraining run.
